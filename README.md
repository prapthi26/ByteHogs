HUMMERBOT AI 

An Intelligent Four-Wheel Robot

Team Name: Byte Hogs
Hackathon: Avishkar Hackathon
Domain: IoT and Embedded Systems

About the Project:

Hummerbot AI is a four-wheel robotic vehicle developed using Arduino and embedded systems. It is designed to support Bluetooth-based manual control and autonomous navigation using sensors.

The project aims to demonstrate robotics, sensor integration, motor control and wireless communication.

Key Features:

- Bluetooth-based manual robot control
- Autonomous navigation
- Ultrasonic obstacle detection
- IR sensor-based detection
- Four-wheel drive mechanism
- Emergency stop functionality

Hardware Components:

- Arduino Uno
- L298N Motor Driver
- Four DC Geared Motors
- HC-05 Bluetooth Module
- HC-SR04 Ultrasonic Sensor
- Two IR Sensors
- Robot Chassis
- Battery and connecting wires

Software and Technologies:

- Arduino IDE
- Embedded C/C++ (Arduino programming)
- Java (Android application)
- Bluetooth Serial Communication

Working Principle:

The Arduino Uno acts as the main controller of the robot.

The Bluetooth module receives commands from the Android application. The Arduino processes these commands and controls the motors through the L298N motor driver.

The ultrasonic and IR sensors help detect obstacles and support autonomous navigation.

Project Structure:

- "Arduino_Code" – Arduino program
- "Android_App" – Android application source code
- "Images" – Robot photographs, circuit diagram
- "Docs" – Project presentation

Future Improvements:
